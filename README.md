# 🧮 MathGPT Clone App
A MathGPT-inspired math problem solver named EquationAI is built with **React**, **TypeScript**, and **Vite**. Enter any math problem from basic arithmetic to advanced equations and get instant, step-by-step solutions powered by AI.

## ✨ Features
 
* **AI-Powered Solving**: Enter any math problem and receive instant, step-by-step solutions.
* **Wide Topic Support**: Handles arithmetic, algebra, calculus, and more.
* **Chat-Style Interface**: Ask questions naturally in a clean, conversational UI.
* **Step-by-Step Breakdowns**: Solutions are explained clearly, one step at a time.
* **Fast Development**: Powered by Vite HMR for a lightning-fast dev experience.
* **Fully Typed**: Built with TypeScript for reliability and maintainability.
## 🛠️ Tech Stack
 
* **React**: Component-based UI library for building interactive interfaces.
* **TypeScript**: Strongly typed superset of JavaScript for safer, cleaner code.
* **Vite**: Next-generation frontend tooling with instant HMR.
* **CSS3**: Custom styling with variables, Flexbox, and Grid layout.
* **AI API**: Powers intelligent math problem solving and step-by-step explanations.
## 🚀 Getting Started
 
To run this project locally on your machine, follow these steps:
 
1. Clone the repository
```
git clone https://github.com/Aly26ssa/mathgpt-clone.git
```
 
2. Navigate to the project directory
```
cd mathgpt-clone
```
 
3. Install dependencies
```
npm install
```
 
4. Set up environment variables
   * Duplicate the `.env.example` file and rename it to `.env`
   * Fill in the required API keys as listed in the example file
5. Launch the application
```
npm run dev
```
